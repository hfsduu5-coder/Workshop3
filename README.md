# CTF Workshop — Cyber Team

An interactive Arabic-first presentation for a **Capture The Flag (CTF)** workshop by Cyber Team.

## Overview

This project packages the workshop as a single responsive web page with slide-style navigation and a cybersecurity-inspired visual interface. It is designed to make introductory CTF material easier to present in workshops and student training sessions.

## Features

- Arabic RTL interface
- Interactive slide-based presentation
- Responsive layout
- Cybersecurity-themed visual design
- Progress and navigation controls
- Runs directly in a modern web browser

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Run Locally

No build process is required.

1. Clone or download the repository.
2. Open `index.html` in a modern browser.

## Purpose

Built for educational workshops and cybersecurity learning activities.

## Responsible Use

Security concepts presented in this project are intended for education, authorized labs, CTF environments, and ethical security research only.
